# Markdown 文档中文化守则

> 关联原子需求：**DOC-03**（基线与规则，P0）
> 前置：`docs/zh-CN/glossary.md`（DOC-01 术语表与排版规则）
> 适用对象：全仓 69 个 `.md`（docs/ 45 个、根目录 6 个、仓内散落 16 个）
> 版本：v1（2026-11-01）

## 1. 总则

1. 只翻译「人读的叙述文本」。
2. 一切**标识符、命令、路径、URL、文件名、Schema 字段名、许可文本**不翻译（见术语表第 3 节）。
3. 中英文/数字之间加一个半角空格，标点用中文全角（决策 5）。
4. 保留文件的整体结构：标题层级、列表符号、表格列数、代码围栏、front-matter、HTML 标签都不得改变。
5. 一个文件的翻译在一个 PR 内完成，不跨 PR 拆 half-translated 状态。

## 2. 逐元素的处理规则

| 元素 | 规则 |
| --- | --- |
| 标题 | 翻译文字，保留 `#` 层级与顺序编号 |
| 正文段落 | 翻译；每个要点单独成句，不要为了对齐原文而保留英语语序 |
| 代码块（``` **围栏内的全部内容**） | **默认整体不改动**，包括其中的注释。它是给用户复制执行的可执行素材，不是叙述文本 |
| 行内代码（`` `...` ``） | 不翻译，连同里面的 `.jsonc`、`x:Uid` 等标记保持原样 |
| 链接 URL | 不改动，含 GitHub permalink 与 `#L###` 行号锚点 |
| 链接文字 | 翻译：`[Learn more](https://...)` → `[了解更多](https://...)`；URL 部分不动 |
| **文内锚点**（`#章节名`） | 若被指向的标题被翻译，锚点必须同步翻译为 GitHub 的 slug（空格转 `-`、去掉标点、保留中文）。**这是最容易漏的一项** |
| 图片路径 | 不改动；`alt` 文本翻译 |
| 表格 | 列名与单元格中的叙述翻译；单元格中的标识符不译；列数不变 |
| 列表符号 | `-`/`*`/`1.` 保持原样 |
| 徽章/图片式 badge | 保留原始 Markdown，不译其中的 shield.io 参数 |
| Issue/PR/Milestone 编号 | 保留（`#2072`） |
| 目录名/文件名 | 不翻译（含 `docs/specs/#2072 - Add some PowerToys utilities/` 这种带空格与井号的路径） |
| HTML 标签（`<br>`、`<kbd>`） | 保留标签，标签内的可译文字照常 |
| Tables of Contents / 目录列表 | 翻译文字，链接锚点按上面的规则同步 |

## 3. 类别特例

| 文档类别 | 特例处理 |
| --- | --- |
| 接口参考（`docs/extensions/environments/Interfaces/*.md`） | 接口签名、枚举值、方法名全部不译；只译说明性段落 |
| 设计规格（`docs/specs/**`） | Issue 编号、参与人、里程碑名不译 |
| 示例配置（`docs/sampleConfigurations/**`） | YAML/DSC 的键名、schema 字段、命令不译；README 叙述照常 |
| 治理文档（README、CONTRIBUTING、SECURITY、SUPPORT、CODE_OF_CONDUCT） | 邮箱地址、官方准则链接、CLA/商标声明保留英文；可在文首加一行「本文为中文翻译版」说明 |
| PR/Issue 模板（`.github/**`） | 模板里的 YAML 字段名（`title:`、`labels:`）不译；说明性文字翻译 |
| 测试场景清单（`**/TestingScenarios/*.md`） | 步骤里的按钮/菜单名若指向 UI 文案，用 AutomationId 或加注英文原文，避免本地化后失效 |

## 4. 禁止事项

1. 禁止翻译代码块内容、命令、包名、环境名。
2. 禁止调整章节顺序或合并/拆分段落（保持与英文原文一一对应，便于复核）。
3. 禁止改动图片与文件本身的路径。
4. 禁止把英文标点留在中文句子里（科技符号除外，如 `AssemblyName`、`{0}`、`800+`）。
5. 禁止随意补写原文没有的内容；需要澄清时可加「（译者注：…）」。

## 5. 自检清单（每个 PR 必过）

- [ ] 术语与 `glossary.md` 一致（仓库 vs 存储库、提供程序 vs provider 等）。
- [ ] 中文与英文/数字之间有半角空格，标点为全角。
- [ ] 代码块、命令、标识符、URL、文件路径未被改动。
- [ ] 所有相对链接可达、图片路径存在（`build/scripts/Translation/DocInventory.ps1 -Check`）。
- [ ] 翻译过的标题若被文内锚点引用，锚点已同步更新。
- [ ] 表格列数、代码围栏、标题层级与原文一致。
- [ ] 文件整体中文覆盖率 100%（无遗漏的英文段落）。
